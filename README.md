# F.CSA313 — Playwright UI автомат тестийн лаборатори

## Лабораторийн ажлын зорилго

Энэхүү лабораторийн ажлаар Playwright ашиглан вебийн UI функциональ автомат тест боловсруулсан.

Тестүүдийг **SauceDemo** веб сайт дээр хийсэн.

Лабораторийн ажлын хүрээнд дараах 3 үндсэн тестийг боловсруулсан:

1. Амжилттай нэвтрэх тест
2. Амжилтгүй нэвтрэх тест
3. Нэвтэрсний дараа барааг сагсанд нэмэх тест

## Ашигласан технологи

* Playwright
* TypeScript
* Node.js
* Git
* GitHub

## Тестүүдийн тайлбар

### 1. Амжилттай нэвтрэх

Зөв хэрэглэгчийн нэр болон нууц үг ашиглан системд нэвтэрнэ. Нэвтэрсний дараа `Products` хэсэг харагдаж байгаа эсэхийг шалгана.

### 2. Амжилтгүй нэвтрэх

Буруу нууц үг ашиглан нэвтрэхийг оролдоно. Системээс алдааны мэдээлэл гарч байгаа эсэхийг шалгана.

### 3. Барааг сагсанд нэмэх

Зөв хэрэглэгчийн мэдээллээр нэвтэрсний дараа эхний барааг сагсанд нэмнэ. Сагсанд 1 бараа нэмэгдсэн эсэхийг шалгана.

## Locator ашиглалт

Тестүүдэд Playwright-ийн орчин үеийн locator-уудыг ашигласан.

* `getByRole()`
* `getByText()`
* `getByPlaceholder()`

XPath-ийг ашиглаагүй. XPath нь веб хуудасны бүтэц, DOM-ийн байрлалаас ихээхэн хамаардаг тул вебийн бүтэц өөрчлөгдөх үед тест эвдрэх магадлал өндөр. Харин Playwright-ийн орчин үеийн locator-ууд нь хэрэглэгчийн харж байгаа элемент болон accessibility мэдээлэлд тулгуурладаг учраас унших, засварлахад хялбар.

## Тестийн тусгаарлалт

Тест бүр бие даасан байдлаар ажилладаг. Тест бүр SauceDemo-ийн login хуудаснаас эхэлдэг бөгөөд өмнөх тестийн үр дүнгээс хамаардаггүй.

Амжилттай нэвтрэх болон бараа сагслах тестүүдийн төгсгөлд logout хийж тестийн төлөвийг цэвэрлэсэн.

## Playwright ба Selenium-ийн харьцуулалт

Playwright болон Selenium нь веб автомат тест хийхэд өргөн ашиглагддаг хэрэгслүүд юм. Selenium нь олон жилийн турш ашиглагдаж байгаа бөгөөд олон төрлийн програмчлалын хэл болон веб хөтчийг дэмждэг. Playwright нь Chromium, Firefox, WebKit зэрэг хөтчүүдийг дэмждэг. Playwright нь auto-waiting, screenshot, video, trace зэрэг автомат тест хийхэд хэрэгтэй олон боломжийг өөртөө багтаасан байдаг. Selenium нь WebDriver стандартыг ашигладаг бол Playwright өөрийн browser automation механизмыг ашигладаг. Playwright-ийг орчин үеийн веб application тест хийхэд тохиромжтой, ашиглахад хялбар гэж үзэж болно. Selenium нь олон төрлийн систем болон хуучин төслүүдтэй ажиллахад өргөн хэрэглэгддэг. Аль хэрэгслийг сонгох нь төслийн шаардлага, багийн туршлага болон ашиглаж байгаа технологиос хамаарна.

## Тест ажиллуулах

Бүх тестийг ажиллуулах:

```bash
npx playwright test
```

Тодорхой тестийг ажиллуулах:

```bash
npx playwright test tests/mytest.spec.ts
```

Trace-тэй ажиллуулах:

```bash
npx playwright test tests/mytest.spec.ts --trace on
```

HTML report харах:

```bash
npx playwright show-report
```

## Дүгнэлт

Энэхүү лабораторийн ажлаар Playwright ашиглан UI автомат тестийн үндсэн ойлголтуудыг хэрэгжүүлсэн. Нэвтрэх, буруу нэвтрэх болон барааг сагсанд нэмэх үйлдлүүдийг автоматжуулж шалгасан. Мөн орчин үеийн locator болон assertion-уудыг ашигласан.
